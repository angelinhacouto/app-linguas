# Imagens dos Super-Heróis

Coloque aqui **8 imagens PNG** com o rosto/personagem fiel ao original.

## Arquivos necessários

| Arquivo | Herói |
|---------|--------|
| `ironman.png` | Homem de Ferro |
| `batman.png` | Batman |
| `superman.png` | Super-Homem |
| `spider-man.png` | Homem-Aranha |
| `hulk.png` | Hulk |
| `thor.png` | Thor |
| `wolverine.png` | Wolverine |
| `wonder-woman.png` | Mulher-Maravilha |

## Recomendações

- **Formato:** PNG (fundo transparente de preferência)
- **Tamanho:** 400×400 px ou maior (quadrado)
- **Conteúdo:** rosto ou busto do personagem, bem visível
- **Estilo:** imagem oficial, fan art ou ilustração que você tenha direito de usar

## Como adicionar

1. Salve as imagens nesta pasta com os nomes exatos acima
2. Rode `npm run deploy` para publicar no site

Ou envie as 8 fotos no chat do Cursor que eu adiciono para você.
